# Licenses and third-party notices

Lifecycle: current

Sense6's source code and documentation use the [MIT license](LICENSE). The
built website also includes dependency code and font files with their own
notices.

| Material in the current build | License | Authoritative notice |
| --- | --- | --- |
| Sense6 code, documentation and repository-generated graphics | MIT | [LICENSE](LICENSE) |
| BrontoUI CSS and browser behavior from `@ponchia/ui` | MIT | Installed package `node_modules/@ponchia/ui/LICENSE` |
| Doto font files, weights 400–900 | SIL Open Font License 1.1 | Installed package `node_modules/@ponchia/ui/fonts/OFL.txt` |

The production build writes `dist/third-party-notices.txt`. It includes the
full copyright and license texts copied verbatim from these sources, the
installed BrontoUI version and the font files actually emitted by Vite. Keep
that generated file with any redistributed build.

The Doto notice identifies the Doto Project Authors and its upstream project,
[oliverlalan/Doto](https://github.com/oliverlalan/Doto). BrontoUI's optional
Inter and JetBrains Mono fonts are present in the dependency package but are
not emitted by the current Sense6 build.

## Maintaining the inventory

[The notice generator](scripts/write-third-party-notices.mjs) runs after the
static-page generator in `npm run build`. It compares every emitted font's
bytes with the reviewed Doto files in the installed package. Missing notices,
unrecognized font data, a new runtime dependency, changed package-license
metadata or a dependency version that differs from the lockfile stop the
build. Review and extend the inventory when those inputs change.

The original license files stay in their owning package instead of being
copied by hand into this repository. No network request is needed to generate
the notice after `npm ci`. Development tools have their own package licenses;
this inventory covers materials distributed with the website.

## Scientific references and graphics

Sense6 links to scientific publications and standards through
[src/exams/sources.js](src/exams/sources.js) and the Learn content. These are
method references; their inclusion does not imply endorsement or transfer
the cited publications' rights to Sense6.

The social SVG and PNG files are generated by
[scripts/generate-social-images.mjs](scripts/generate-social-images.mjs).
The experiment stimuli are drawn by the source code. Retain these assets and
their generators together; they are intentional product files.
